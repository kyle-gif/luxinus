# Codex 로그인과 사진 편집 UX 후속 변경

> 이 문서는 첫 로그인·UX 변경의 기록입니다. 이후 추가한 왼쪽 채팅·이미지 입력·모델 선택·앱 도구·Figma식 조작은 [최신 AI 작업실 문서](ai-workspace.md)를 따릅니다. 아래 텍스트 전용 범위와 63개 테스트 수는 당시 기준입니다.

2026-09-09, 사용자의 후속 요청 기준. 최초 통합 지시서의 네트워크 강제 차단·로컬 전용 AI 요구는 이 요청으로 변경되었다. 기존 로컬 모델은 유지한다.

## 사용 방법

1. 앱을 다시 실행하고 상단 **AI 설정 → GPT Codex → ChatGPT로 로그인**을 누른다.
2. 공식 브라우저에서 로그인을 마친다. 설정을 닫으면 아직 진행 중인 로그인은 취소된다.
3. **AI 보정** 또는 `⌘/Ctrl+K`에서 GPT Codex를 선택하고 원하는 밝기·색감 변화를 입력한다.
4. 변경할 수치를 확인하고 **사진에서 미리보기 → 사진 1장에 적용**한다. 기존 실행 취소로 되돌릴 수 있다.

로컬 모델은 **AI 설정 → 로컬 모델 → 모델 실행 확인**을 거쳐 계속 사용한다. 제공자 선택은 앱에 저장되며 연결 실패 시 자동으로 다른 제공자를 사용하지 않는다.

## 변경한 동작

- **사진 목록 / 사진 편집**, **기본 보정 / 전체 보정**, **AI 보정 / AI 설정**으로 화면 명칭을 바꿨다. 밝은 부분·어두운 부분·흰색·검은색·질감·부분 대비·가장자리 밝기·필름 입자 등 실제 조작을 이해하기 쉬운 이름으로 통일했다. 기존 그림자·하이라이트 등의 수치 요청도 호환한다.
- `⌘/Ctrl+Z`, `⌘/Ctrl+Shift+Z`, `Ctrl+Y`를 공통 처리하고 실행 취소·다시 실행 버튼에 단축키를 표시한다. 사진 목록, 편집 화면, 버튼·슬라이더 포커스에서 동작한다. 텍스트 입력의 기본 Undo를 가로채지 않고 모달 뒤의 사진·로딩 중 상태·진행 중인 드래그는 변경하지 않는다.
- 별도의 기하/지오메트리 섹션을 없애고 **자르기·수평**에 비율·±45° 수평 조절·좌우/상하 뒤집기·초기화·완료를 모았다. 기존 셰이더와 좌표 포맷을 보존한다. 90° 방향 전환이나 원본에 고정되는 마스크 좌표계를 새로 구현한 것은 아니다.
- AI 설정의 실행 경로·체크섬 등 기술 정보는 펼쳐 볼 수 있도록 줄이고, 상태와 다음 동작을 먼저 보여준다. 저장된 Codex 계정은 **로그인 정보 저장됨**으로 표시하며, 서비스에 실제 연결됐다고 표시하지 않는다.

## Codex 구현

설치된 공식 `codex-cli 0.153.4`의 help·feature registry·생성 JSON 스키마와 [공식 App Server 문서](https://learn.chatgpt.com/docs/app-server)의 stdio JSON-RPC, 로그인, 대화, 구조화 출력 규격을 확인했다. 별도 API 키로 전환하지 않는다.

- `src/main/codex-client.ts`, `codex-protocol.ts`: 지연 실행, 공식 ChatGPT 로그인 시작·취소·로그아웃, 계정 확인, ephemeral 대화, 응답 스키마, 취소·제한시간·자식 종료를 처리한다.
- `src/shared/agent-provider.ts`: Codex에 보낼 스칼라 값과 불투명 사진 ID만 구성한다. 모든 객체 필드를 필수로 둔 응답 스키마의 `changes` 목록을 엄격히 검사한 뒤 기존 편집 patch 검증으로 변환한다. 중복·미지원 항목·범위 초과·사진 ID 불일치·임의 필드는 거부한다.
- `src/main/local-agent.ts`: 제공자만 선택해 추론하고, 로컬/Codex 모두 같은 제안 보관·원본 경로 권한·sidecar 해시·적용·저장·Undo 경로를 사용한다. Codex에는 작은 로컬 모델에서 확인된 상대 계산 제한을 적용하지 않는다.
- `src/preload/index.ts`: 필요한 계정 동작만 개별 IPC로 노출한다. renderer에는 인증 토큰이나 범용 IPC·Node 접근을 주지 않는다.
- 인증은 `~/Library/Application Support/luxinus/codex`의 전용 `CODEX_HOME`에서 공식 CLI가 관리한다. 기존 개발용 계정 토큰을 읽어 복사하지 않는다. 화면 상태용 `connection-state.json`에는 이메일·계획명 등 최소 계정 요약만 저장한다. 요약은 인증 증명이 아니며 실제 보정 요청에서 공식 계정을 다시 확인한다.

앱 시작·일반 사진 작업·AI 설정 열기·평소 상태 새로고침은 Codex 프로세스를 시작하지 않는다. 로그인 버튼과 Codex 보정 요청에서만 시작한다. 사용자가 시작한 로그인 중에는 해당 서버의 로그인 완료 상태를 확인한다. 작업이 끝나거나 취소되면 서버를 종료한다. 사진 픽셀·파일 이름·원본 경로·EXIF는 보정 입력에 포함하지 않는다. 사용자가 직접 입력한 요청 문장에는 사용자가 적은 내용이 그대로 포함된다.

Codex의 shell·웹 검색·이미지·연결 앱·플러그인 기능을 비활성화하고 읽기 전용 실행 정책을 사용한다. 승인·외부 토큰 요청은 거부하고 예상하지 못한 도구 이벤트가 오면 요청을 종료한다. 설치 버전에는 모든 내장 도구를 한 번에 제거하는 검증된 옵션이 없으므로, 이 경로를 임의 Codex 실행 파일까지 격리하는 완전한 보안 경계로 주장하지 않는다. 원본 파일 쓰기는 앱의 적용 경로에 포함되지 않는다.

## 네트워크 정책과 실제 확인

Node 네트워크 API 전역 가로채기, main/숨은 디코더 세션의 모든 외부 요청 거부, 로컬 모델의 `(deny network*)`를 제거했다. CSP의 HTTP(S)/WS(S) 연결도 허용한다. 스크립트 실행·외부 문서 탐색·IPC 발신 창 검증·원본 파일 보호는 유지한다.

일반 사진·ONNX·로컬 언어 모델은 서비스 요청을 만들지 않는다. 테스트 도구는 요청을 관찰만 하며 생산 코드의 차단 여부를 바꾸지 않는다. 특히 첫 검사의 디코더 관찰기가 단일 `onBeforeRequest` listener를 덮는 결함은 별도 리뷰에서 찾아 `onBeforeSendHeaders` 관찰로 고쳤고 실제 실행을 반복했다.

- 최신 실제 Electron 복원 검사: 일반 경로 관찰 요청 0, 명시적 합성 loopback 요청 5건 성공(main·화면·숨은 디코더·두 utility). 실제 ONNX CPU 추론·GPU 내보내기·중단 후 재시작·원본/기존 출력 보존 통과.
- 로컬 모델: 깨진 dylib 링크 18개를 설치 폴더 내부 상대 링크로 복구했고 일반 파일 SHA256 전후 동일. 실제 단일 한국어 수치 요청·취소 통과. 파일 읽기/쓰기 및 다른 실행 파일 보호 유지, 명시적 loopback 연결 허용. 일반 호스트 경로 관찰 요청 0.
- 네트워크 검사는 Node JS API와 Chromium 요청 관찰이다. 전체 OS 패킷이나 임의 native 코드의 모든 통신을 감시한 결과는 아니다.

보고서는 `.omc/artifacts/electron-restoration-smoke.json`, `.omc/local-agent-smoke/model-smoke.json`에 있다. 작은 로컬 모델의 여러 항목 수치 요청 오인식은 여전히 존재하며, 요청·출력 대조가 적용을 거부한다. 직접 모델 진단의 `policyPassed:true`와 `allSupportedCasesMatched:false`를 구분한다.

## 인증 검증 범위

실제 사용자의 ChatGPT 로그인 완료, 구독 권한·사용량, 인증된 Codex 모델 응답은 검증하지 않았다. 실제 App Server 상태 확인 실행은 외부 통신 가능성을 이유로 자동 승인 검토에서 거절되어 실행되지 않았다. 이후 일반 상태 확인을 프로세스 실행 없는 로컬 조회로 바꾸었다. 실제 브라우저 로그인은 사용자가 위 버튼을 눌러 진행한다.

Codex 프로토콜의 정상 응답·로그인·취소·재시작·오류 검사는 모의 stdio peer로 수행하며 실제 서비스 인증 증거와 구분한다. Electron에서 모의 계정 응답으로 검사하는 UI도 실제 로그인 성공으로 간주하지 않는다.


## 최종 로컬 실행 결과

- 최종 `npm run typecheck`(Node/Web), `npm test` **63/63**(실패·skip·todo 0), `npm run build`, `git diff --check` 통과. 별도 작성자가 네트워크 정책·AI UI·로그인 경합·요청 검증을 검토했고, 연속 드래그 변경도 작성자와 다른 검토자가 확인했다.
- 실제 Electron 기본 편집: 1440/1024 화면, 공통 Undo/Redo, 텍스트 기본 Undo 보존, 모달 뒤 편집 차단, 자르기·수평·반전·초기화, PNG 640×400/320×200 내보내기 통과. 실제 crop 핸들을 이동하다 550ms 멈추고 다시 이동해도 Undo 1회로 복원하며, 드래그 중 Cmd+Z가 값을 덮지 않는 것을 확인했다. 원본 해시 불변, renderer 오류 0.
- 실제 로컬 모델 UI: 모델 실행 확인, 예시에 없는 대비17, 새 화면 명칭 “어두운 부분 값을 정확히 20으로”, 실제 픽셀 미리보기/해제, 승인 저장/Undo/Redo, 저장 대기 중 취소, XMP byte 보존/Undo, 창 닫기 시 저장 완료를 통과했다. 최신 한국어 실행 확인은 3.892초였으며 합성 원본은 그대로다.
- 로컬 모델의 허용 항목 설명을 길게 바꾸자 대비17이 틀리는 회귀가 발생했다. 기존 검증 프롬프트를 복원하고 **명시적 수치 요청의 화면 명칭만** 기존 모델 명칭으로 변환해 다시 통과했다. 숫자·단위·상대표현과 일반적인 자연어 문장은 바꾸지 않으며, 원래 사용자 요청과 모델 출력의 엄격한 일치 검증을 유지한다. 이 회귀와 작은 모델의 기존 다중 항목 실패는 모델 품질이 제한적이라는 근거다.
- 실제 Electron Codex UI: 생산 코드의 설치 CLI 검색·일반 상태 조회 2회에서 자식 실행 0·요청 0. 이후 모의 계정으로 로그인/로그아웃/제공자 전달/창 닫기/늦은 초기 응답/새로고침/새 로그인 보존을 확인했다. 초기 로그인 상태에서 첫 poll 전에 닫기(3ms)도 취소됐으며 1024px 화면·Tab/Escape·포커스 복귀·넘침 검사를 통과했다. **실제 원격 계정 인증이나 모델 추론 결과는 아니다.**
